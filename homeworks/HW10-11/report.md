# HW10-11 – компьютерное зрение в PyTorch: CNN, transfer learning, detection/segmentation

## 1. Кратко: что сделано

Кратко: что сделано
Часть A (классификация): Выбран датасет CIFAR100 — 100 классов, изображения 32×32 RGB. Этот датасет сложнее CIFAR10 (больше классов, мелкая гранулярность), что позволяет лучше продемонстрировать преимущество transfer learning.
Часть B (structured vision): Выбран датасет OxfordIIITPet, трек segmentation. Датасет содержит изображения питомцев с pixel-level разметкой (trimap). Выбран потому, что это понятный сценарий бинарной сегментации (пет/фон) с готовой предобученной моделью из torchvision.
Что сравнивалось:
Часть A: 4 эксперимента (C1-C4) — простая CNN vs аугментации vs transfer learning (head-only vs fine-tune)
Часть B: 2 режима постобработки (V1-V2) — базовый порог vs альтернативная постобработка

## 3. Данные

### 3.1. Часть A: классификация

Датасет: CIFAR100
Разделение: train/val/test = 80%/20%/test (официальный test split)
Train: ~40,000 изображений
Val: ~10,000 изображений (выделено из train с фиксированным seed)
Test: 10,000 изображений (официальный test set)
Базовые transforms:
transforms.ToTensor(),
transforms.Normalize(CIFAR100_MEAN, CIFAR100_STD)
Augmentation transforms:
transforms.RandomHorizontalFlip(p=0.5),
transforms.RandomCrop(32, padding=4),
transforms.ColorJitter(brightness=0.1, contrast=0.1, saturation=0.1),
transforms.ToTensor(),
transforms.Normalize(CIFAR100_MEAN, CIFAR100_STD)
Комментарий: CIFAR100 содержит 100 классов, сгруппированных в 20 суперклассов (например, "рыбы", "цветы", "транспорт"). Изображения маленькие (32×32), что делает задачу сложной для простых CNN. 100 классов требуют более выраженных признаков, что хорошо демонстрирует преимущество предобученных моделей.

### 3.2. Часть B: structured vision

Датасет: OxfordIIITPet
Трек: segmentation
Что считается ground truth: Бинарная маска, где 1 = питомец (foreground), 0 = фон. Исходный trimap (1=pet, 2=bg, 3=boundary) конвертируется в бинарную маску.
Какие предсказания использовались: Предсказания модели DeepLabV3-ResNet50 (предобучена на COCO-with-VOC). Классы cat и dog из COCO объединяются как foreground.
Комментарий: Постановка разумна, потому что OxfordIIITPet предоставляет pixel-level разметку для 37 пород кошек и собак. Использование предобученной модели без fine-tuning позволяет оценить zero-shot способность модели обобщать на новые домены (COCO → OxfordIIITPet).

## 4. Часть A: модели и обучение (C1-C4)

Опишите коротко и сопоставимо:

- C1 (simple-cnn-base): Простая CNN (3 conv блока: 32→64→128 фильтров) + FC, без аугментаций
- C2 (simple-cnn-aug): Та же архитектура CNN, но с аугментациями (flip, crop, color jitter)
- C3 (resnet18-head-only): ResNet18 с pretrained weights (ImageNet), backbone заморожен, обучается только fc
- C4 (resnet18-finetune): ResNet18 с pretrained weights, разморожены layer4 + fc, разные LR для backbone/head

Дополнительно:

Loss: CrossEntropyLoss
Optimizer(ы):
C1, C2: Adam(lr=1e-3)
C3: Adam(lr=1e-3) (только fc)
C4: Adam(lr=1e-4 для layer4, lr=1e-3 для fc)
Batch size: 64 (CNN), 32 (ResNet)
Epochs (макс): 3 (FAST_MODE)
Критерий выбора лучшей модели: Максимальная best_val_accuracy

## 5. Часть B: постановка задачи и режимы оценки (V1-V2)


### Если выбран segmentation track

Модель: DeepLabV3-ResNet50 с весами COCO_WITH_VOC_LABELS_V1
Что считается foreground: Классы cat (idx=15) и dog (idx=18) из COCO, объединённые через логическое ИЛИ
V1 (базовая постобработка): Порог > 0 на logits для классов cat/dog
V2 (альтернативная постобработка): Порог > 0.7 (более строгий) + морфологическая очистка (binary opening/closing через scipy.ndimage)
Как считался mean IoU: Для каждого изображения вычисляется IoU = intersection / union между предсказанной и GT маской, затем усредняется по выборке из 50 примеров
Дополнительные метрики: median_IoU, std_IoU

## 7. Анализ

(8-15 предложений)

Нужно прокомментировать:

Простая CNN на CIFAR100: Простая CNN (C1) показывает результат ~28.5% accuracy, что ожидаемо для 100 классов при обучении с нуля. Маленький размер изображений (32×32) и большое число классов требуют более выразительных признаков, которые простая архитектура из 3 свёрточных блоков не может полноценно извлечь за 3 эпохи.
Аугментации (C2 vs C1): В текущем эксперименте аугментации ухудшили результат (0.1934 vs 0.2853). Вероятная причина: при очень малом числе эпох (3 в FAST_MODE) аугментированные данные не успевают "проявить" свой регуляризующий эффект — модель недообучается. При полном обучении (10+ эпох) аугментации обычно дают устойчивое улучшение обобщения, что подтверждается литературой.
Pretrained ResNet18: Предобученная модель (C3) показала значительный прирост до ~56.6% accuracy по сравнению с ~28.5% у простой CNN. Это подтверждает эффективность transfer learning: признаки, выученные на ImageNet (1.2M изображений, 1000 классов), хорошо переносятся на CIFAR100 даже при полностью замороженном backbone.
Head-only vs Fine-tuning: Partial fine-tuning (C4) превзошёл head-only (C3) на ~15.6 процентных пунктов (72.2% vs 56.6%). Разморозка layer4 с меньшим learning rate (1e-4) позволила модели адаптировать высокоуровневые признаки под специфику CIFAR100, что особенно важно при доменном сдвиге (натуральные изображения ImageNet -> маленькие 32×32 картинки CIFAR100).
Метрика для сегментации: Mean IoU подходит для задачи бинарной сегментации, потому что учитывает как precision, так и recall на pixel level и не завышается при дисбалансе классов (фон доминирует над объектом). Для нашей задачи это более информативно, чем pixel accuracy.
V1 vs V2: Переход от V1 к V2 увеличил mean IoU с 0.282 до 0.326 (+15.6%). Более строгий порог (0.7 вместо 0) уменьшает ложные срабатывания на фоне, а морфологическая очистка (opening/closing) убирает мелкий шум, не затрагивая основные области питомцев.
Типичные ошибки модели:
Неправильная сегментация на границах объектов (размытые края)
Пропуск питомцев на сложном/текстурном фоне
Ложные срабатывания на объектах, визуально похожих на животных (плюшевые игрушки, узоры)
Ограничения zero-shot: модель не знает специфичные породы из OxfordIIITPet, только общие классы cat/dog из COCO

## 8. Итоговый вывод

(3-7 предложений)

Базовый конфиг классификации: Выбран C4 (ResNet18 fine-tune) — лучшая точность (72.9% test) при разумных вычислительных затратах. Для продакшена: заморозить layer1-3, дообучать layer4+fc с разными LR.
Transfer learning на практике: Предобученные веса дали +44% к accuracy (C4 vs C1). Head-only (C3) — быстрый базлайн за 1-2 эпохи, fine-tuning (C4) — +15% сверху при тех же данных. Вывод: всегда начинать с pretrained, fine-tune добавлять если нужно качество.
Сегментация и метрики: Zero-shot DeepLabV3 на OxfordIIITPet дал mean_IoU=0.33 (V2). Для прототипа — достаточно, для продакшена требуется fine-tuning на целевом датасете. IoU корректнее accuracy при дисбалансе фон/объект.
Что сделано в работе: Реализован полный пайплайн CV в PyTorch — от загрузки данных (CIFAR100, OxfordIIITPet) через 4 эксперимента классификации до оценки сегментации с двумя режимами постобработки. Все артефакты сохранены, эксперименты воспроизводимы (seed=42).
